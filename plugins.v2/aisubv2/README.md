# AI字幕自动生成(AiSub v2)

自动生成视频字幕，并使用大模型将字幕翻译成中文。

基于 [autosub](https://github.com/lightolly/MoviePilot-Plugins) 修改并适配v2，感谢原作者

## 功能特点

- 支持从视频音轨中提取字幕（使用faster-whisper）
- 支持从视频内嵌字幕中提取字幕
- 支持从外挂字幕文件中提取字幕
- 支持使用大模型将字幕翻译成中文（独立配置，不再依赖 ChatGPT 插件）
- 整文件按字幕序号（id）翻译：时间轴原样保留，模型无法改动时间戳
- 响应被截断时自动补译，仍不完整则回退为分块翻译
- 支持「仅输出中文」与「译文+原文双语」两种输出
- 支持「已存在中文字幕则跳过」
- 支持多种字幕提取语言偏好设置
- 支持监听媒体入库事件自动执行字幕生成
- 支持手动触发字幕生成任务
- 支持任务队列机制，确保并发安全
- 支持任务状态列表展示（等待中 / 进行中 / 已完成 / 失败）

## 配置说明

### 基础配置

| 配置项      | 说明                     | 默认值    |
|----------|------------------------|--------|
| 启用插件     | 是否启用插件                 | 否      |
| 清除历史记录   | 清除已完成的任务记录（完成、跳过或失败）   | 否      |
| 媒体入库自动执行 | 监听到媒体入库事件后自动执行字幕生成     | 是      |
| 手动执行一次   | 保存配置后立即执行一次任务          | 否      |
| 发送通知     | 是否发送任务执行通知             | 否      |
| 文件大小（MB） | 最小处理的视频文件大小，小于该值的文件不处理 | 10     |
| 字幕源语言偏好  | 设置字幕提取的优先级策略           | 英文优先 |
| 翻译为中文    | 是否使用大模型将字幕翻译成中文        | 否      |
| 已存在中文字幕则跳过 | 外挂或内嵌字幕中检测到中文时跳过该视频 | 是 |

### ASR配置（语音识别）

| 配置项                 | 说明               | 默认值  |
|---------------------|------------------|------|
| 允许从音轨提取字幕           | 是否允许从视频音轨中提取字幕   | 是    |
| faster-whisper 模型选择 | 使用的 Whisper 模型大小 | base |
| 使用代理下载模型            | 是否使用代理下载模型       | 是    |

### 大模型翻译配置

| 配置项       | 说明                                        | 默认值        |
|-----------|-------------------------------------------|------------|
| 接口类型      | openai_chat / openai_responses / anthropic_messages | openai_chat |
| Base URL  | 接口地址前缀（不要带 `/v1`，程序会自动拼接）                  | 空          |
| API Key   | 接口密钥（密码框，仅保存在插件配置中）                        | 空          |
| 模型名称      | 例如 deepseek-flash                          | 空          |
| 推理强度      | low / high / max                          | high       |
| 最大输出token数 | 单次请求的最大输出 token（Responses/Anthropic 必填）    | 64000      |
| LLM请求重试次数 | 请求失败/缺条时的重试次数                              | 3          |
| 仅输出中文     | 开启只输出译文；关闭输出「译文+原文」双语                      | 否          |

#### 三种接口的端点映射

| 接口类型 | 请求端点 | 认证 | 备注 |
|------|------|------|------|
| openai_chat | `POST {base}/v1/chat/completions` | `Authorization: Bearer` | 正文取 `choices[0].message.content` |
| openai_responses | `POST {base}/v1/responses` | `Authorization: Bearer` | 取 `output[].content[]` 中 `type=="output_text"` |
| anthropic_messages | `POST {base}/v1/messages` | `x-api-key` + `anthropic-version: 2023-06-01` | 取 `content[]` 中 `type=="text"` |

示例：

- DeepSeek Chat Completions：`Base URL = https://api.deepseek.com`，`模型 = deepseek-flash`
- DeepSeek Anthropic 兼容：`Base URL = https://api.deepseek.com/anthropic`
- Anthropic 官方：`Base URL = https://api.anthropic.com`

| 配置项  | 说明                    | 默认值 |
|------|-----------------------|-----|
| 媒体路径 | 要处理的媒体文件或文件夹绝对路径，每行一个 | 空   |

## 翻译流程说明

1. 读取源字幕（编码依次尝试 utf-8-sig → utf-8 → gbk → latin-1），解析为字幕条目并分配稳定的顺序 id；
2. 将全文组装为一个 JSON 数组 `[{"n":1,"t":"原文"}, ...]`，一次性请求大模型，要求按 `n` 返回 `t` 的简体中文译文；
3. 严格按 id 回写译文，时间轴与序号完全来自源文件，模型输出不会影响时间戳；
4. 若返回缺条或为空，仅对缺失 id 发起补译（默认最多 3 次）；
5. 补译后仍不完整（例如响应被输出 token 上限截断），则按每块 300 条回退分块翻译，每块走同样的 id 协议与补译流程；
6. 最终仍未翻译的条目保留原文并计数，日志汇总并（在开启通知时）发送告警，不会丢失任何原文。

## 中文字幕检测（已存在中文字幕则跳过）

- 外挂字幕：文件名与视频同名，且语言标记属于 `zh|chi|zho|chs|cht|zh-cn|zh-hans|zh-hant|zhong|simp|cn|简体|繁体|中文|机翻`，或内容嗅探为中文；
- 内嵌字幕：字幕流的 `language`/`title` 命中上述标记；未打标记的字幕流会提取到临时 srt 后嗅探内容；
- “中文”判定：以汉字为主且不含平假名/片假名/谚文，按采样条目比例判定。

## 命令行工具

`tools/translate_srt.py` 可以脱离 MoviePilot 直接跑同一套翻译引擎，便于验证：

```bash
export LLM_API_KEY=sk-xxx
python3 tools/translate_srt.py "/path/to/movie.it.srt" \
    --api-type openai_chat --base-url https://api.deepseek.com \
    --model deepseek-flash --verify
```

`--verify` 会逐条比对输入/输出字幕的序号与时间轴是否完全一致；`--zh-only` / `--bilingual` 控制输出形态。

## 字幕提取策略说明

字幕提取优先级：外挂字幕 > 内嵌字幕 > 音轨识别

字幕提取策略的选择主要取决于视频源语言和大模型的翻译能力。对于包含多语言字幕的非英语视频，建议根据以下原则选择策略：

1. 仅英文字幕
    - 仅使用英文字幕作为翻译源
    - 当视频无英文字幕时，使用ASR提取
    - 适用于大模型仅支持中英互译的场景

2. 优先英文字幕
    - 优先使用英文字幕作为翻译源
    - 无英文字幕时，使用其他语言字幕
    - 当所有字幕都不存在时，使用ASR提取
    - 适用于大模型在英译中任务上表现更好的场景

3. 优先原音字幕
    - 优先使用视频原始语言的字幕
    - 无原音字幕时，使用英文字幕
    - 当所有字幕都不存在时，使用ASR提取
    - 适用于大模型支持多语言翻译且翻译质量较好的场景

## 注意事项

1. 翻译功能使用插件内的独立大模型配置（接口类型/Base URL/API Key/模型），不再读取 ChatGPT 插件配置。
2. 首次使用音轨识别功能时，会自动从HuggingFace下载模型。开启"使用代理下载模型"选项会使用MP配置的代理。
3. 媒体路径支持单个文件或文件夹的绝对路径。选择文件夹时会递归处理其中的所有视频文件，外挂字幕将从媒体文件同级目录中查找
4. 整文件翻译只需一次请求；当模型输出被截断时会自动补译并按 300 条分块重试，分块大小是内部常量，不对外暴露。
5. 翻译后的中文字幕会打上“机翻”标签。
6. 插件运行时会启动一个后台线程用于消费任务队列，插件关闭时会清空队列并终止当前任务。
